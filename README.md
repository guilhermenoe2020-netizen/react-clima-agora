Aplicação web desenvolvida com o objetivo de praticar os fundamentos de React por meio da criação de uma aplicação meteorológica que utiliza a API Open-Meteo para consultar condições climáticas e previsões do tempo por cidade.

- **CSS**
- **Open-Meteo API**
- **Lucide React**

## Conceitos praticados

- Componentização com React.
- Gerenciamento de estado com `useState`.
- Consumo de APIs utilizando `fetch`.
- Requisições assíncronas com `async/await`.
- Manipulação de dados JSON.
- Renderização dinâmica de informações.
- Pesquisa de cidades por meio de uma API de geocodificação.
- Estilização responsiva para diferentes tamanhos de tela.

**Front-end:** Vercel

## Como executar o projeto

Pré-requisitos: Node.js e npm instalados.

1. Clone o repositório:

   ```bash
   git clone https://github.com/guilhermenoe2020-netizen/react-clima-agora.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd react-clima-agora/frontend
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie a aplicação:

   ```bash
   npm run dev
   ```

5. Acesse o endereço local exibido no terminal.
